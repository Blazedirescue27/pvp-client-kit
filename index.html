FAQ

Questions Before You Download

Quick answers about the client, the loader and compatibility.

Is pvp-client-kit free to download?+
Yes. pvp-client-kit is free and open source. Every module — aimbot, ESP wallhack, reach, velocity and autoclicker — is included in the same build with no paid tier or license key.
Which Windows versions are supported?+
The loader is built for Windows 10 and Windows 11 (64-bit). It runs alongside standard Minecraft launchers and needs administrator rights only to attach the injector correctly.
How does the injector loader work?+
Launch Minecraft first, then open the pvp-client-kit loader, select the running game process and press Inject. The overlay binds to a hotkey you choose during setup, so you can toggle modules without leaving the game.
Can I share my config profiles?+
Absolutely. Profiles are plain files stored in the client's config folder. Export any profile from the overlay menu to share it with friends or import one tuned for a specific server's PvP meta.
